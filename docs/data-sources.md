# Atlas data sources

This document describes Atlas's current visitor-facing search. It is not a promise of complete coverage, an inventory of every retained operational connector, or a claim that a public source permits republication. The live [source register](https://signal-scout-xi-ruby.vercel.app/sources) reports current source notes and operational health.

## On-demand search

- **Hacker News:** Keyless Algolia comment search, limited to the preceding 30 days and at most 20 results. Atlas checks that every meaningful query term appears in the story title or comment. The sample is English-language and technology-oriented, not a general investor forum. Excerpts remain transient in the browser.
- **Bluesky:** Optional keyless public AppView search, limited to the preceding seven days and at most 25 indexed posts per phrase. The visitor can enter up to three alternate phrases; Atlas submits each phrase separately and labels the exact query. Identical normalized text is collapsed within each query, with the repeat count disclosed on its surviving source entry; a sample dominated by one displayed handle receives a concentration note. Neither note establishes identity or independence. Text is transient, and a post carrying provider labels is displayed without its text preview. Language metadata may be missing. Results are not a full network feed or representative sample. See the [official search API reference](https://docs.bsky.app/docs/api/app-bsky-feed-search-posts) and [Bluesky terms](https://bsky.social/about/support/tos).
- **Global Voices:** Keyless on-demand title/edition metadata search across 12 localized WordPress editions, limited to the preceding 30 days and five results per edition. Atlas locally requires each meaningful query term to appear in the returned headline, because the API may otherwise match article-body text. Body-only matches are omitted; Atlas shows headlines and links, not article bodies. Failed editions are reported as partial coverage. Its five-requests-per-minute IP-keyed limit is in-memory per warm serverless function instance, so it is a best-effort abuse guard rather than a globally consistent quota.
- **Stack Exchange:** Specialist title search for selected communities, limited to the preceding 30 days. Only items whose current API response identifies CC BY-SA 4.0 are shown. Atlas filters locally for every meaningful query term, date validity, and the selected community's canonical host. Phrases shorter than three characters are explicitly marked “Not searched”; they do not block other providers.
- **Lemmy:** Optional visitor-selected public instances with separate requests and a seven-day result window. Each instance may receive a separately supplied phrase. The user must acknowledge that instance's terms/privacy and age rules. Federation can duplicate posts; the results are not country, population, or complete-network samples.

The main query is sent as entered. The optional alternate-phrase field accepts up to three researcher-supplied aliases, spelling variants, or local-language phrases; they are sent separately to Hacker News and Global Voices and, if enabled, Bluesky. Atlas does not infer synonyms or silently translate. Community-specific query fields remain separate. An exact phrase can be surrounded by double quotes for local adjacency filtering where supported; provider-side behavior may still differ.

Each provider request is aborted after 12 seconds. Each source card reports its query, search-start time in UTC, time window, result status, and count. A completed search with zero matches, a provider error/timeout, partial edition coverage, and an intentionally unsearched query are distinct states. When no international-language result appears, the overview distinguishes a completed empty search from partial or unavailable reporting. Every overview excerpt/headline carries a citation ID linked to the matching source entry below. A provider match is not proof of topical relevance; inspect the original item.

## Privacy and retention boundary

The search page keeps results in browser memory for the active page and does not create user search history or save briefs. Search requests go to their respective providers; Global Voices is queried through an Atlas server endpoint with a short-window rate limit using request network information. Atlas/Vercel and source providers may process technical request data under their own operating practices. See the live [privacy notice](https://signal-scout-xi-ruby.vercel.app/privacy).

Search is separate from protected scheduled ingestion and source-monitoring endpoints. Those operational services may retain historical metadata in Supabase. Removing or changing a search UI connector does not delete operational records, migrations, credentials, or historical data.

## Interpretation limits

Returned records are not unique people, frequency of belief, public sentiment, attention, prevalence, investor positioning, or national opinion. English is not a U.S. sample; language, server, edition, and publisher do not establish contributor location. Multiple source labels may repeat one underlying claim. Atlas currently does not synthesize an AI-generated global thesis, establish source independence, measure financial materiality, or connect conversation to company fundamentals. Use it to discover and inspect sources—not as an investment recommendation.
