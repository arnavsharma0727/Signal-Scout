# Data sources

Optional connectors are disabled by default: user-provided APIs, documented free GDELT endpoints, official SEC EDGAR, supplied RSS/Atom feeds, and authorized Naver Search/DataLab APIs. For Korean conversation research, read [Korean source strategy](korean-source-strategy.md). Arbitrary HTML scraping, Google Trends, paywall circumvention, anti-bot bypasses, and unauthorized APIs are prohibited. Connector status and freshness are surfaced without revealing secrets.

The optional Korea MOIS press-release connector is separate from publisher and community feeds. It uses the ministry's documented RSS endpoint without a key; it checks each recent linked article for the MOIS KOGL Type 1 mark and persists only title, original URL, publication time, and license metadata. It provides official-policy context, not market conversation or sentiment. Keep it disabled unless explicitly enabled through `MOIS_PRESS_RELEASES_ENABLED`; see the per-source terms and primary citations in [SOURCES.md](SOURCES.md).
# Current production status

The scheduled app has a keyless Stack Exchange connector across five English-language topical sites and Spanish-, Portuguese-, Japanese-, and Russian-language Stack Overflow. Its first multilingual production run stored 24 items in the rolling 24-hour view with no connector errors; the homepage showed English, Spanish, and Russian items. It stores only individually CC BY-SA 4.0-licensed questions with author/license attribution, omitting post bodies. This is a narrow, query-selected expert Q&A sample, not general social conversation or representative public opinion. Explore also offers a user-triggered live query against one selected community; the request goes directly from the browser to Stack Exchange and neither the query nor results are persisted by Signal Scout. A separate optional Mastodon hashtag viewer directly queries mastodon.social and transiently displays at most 20 public posts from its incomplete federated view, with source/author links and content-warning handling; it stores no posts or derived metrics. Mastodon posts remain author-owned and no blanket content license is implied. GDELT is enabled for one global daily request but its latest production checks still report HTTP 429 and zero stored headlines. No direct publisher RSS feeds are enabled. Historical Google News redirects are excluded and hidden; Hacker News is withheld pending rights review.

## Connector access and operating constraints (reviewed 2026-09-30)

- **RSS/Atom:** Each publisher's terms govern access, excerpts, retention, and republication. The configured Google News redirect feeds were not direct publisher feeds and are rejected; there are currently no direct feeds enabled. Store source links and minimal excerpts only after source-specific use is reviewed. No blanket republication right is inferred from RSS availability.
- **Hacker News Search API:** The documented Algolia-backed API exposes public item/comment search and documents a 10,000-request-per-hour per-IP limit. Public API access does not itself establish reuse/display rights for user comments. Ingestion and display are disabled pending rights clearance. [API documentation](https://hn.algolia.com/api).
- **SEC EDGAR:** Official submissions/XBRL endpoints are public, but SEC asks automated clients to identify themselves with a descriptive User-Agent and caps access at 10 requests/second. Current SEC_USER_AGENT is not configured, so the connector is not enabled. Do not invent or transmit a personal contact address. [SEC fair-access guidance](https://www.sec.gov/about/webmaster-frequently-asked-questions).
- **OpenDART:** The official API is generally free but requires account registration and a 40-character authentication key; quotas can change and are published by the operator. It is not an anonymous no-key source and is not enabled. No account was created and no key requested. [OpenDART usage terms](https://opendart.fss.or.kr/intro/terms.do), [developer guide](https://opendart.fss.or.kr/guide/main.do).
- **GDELT:** The project states its datasets are available without fee and may be redistributed with citation/link attribution. The deployed connector is limited to one global query/day and observes the endpoint's five-second guidance on 429, but recent production runs still fail with HTTP 429. Do not repeatedly probe or evade throttling. [Terms](https://www.gdeltproject.org/about.html), [DOC API overview](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/).
- **Stack Exchange API:** Keyless searches cover English Economics, Money, AI, Data Science, and Security plus Spanish, Portuguese, Japanese, and Russian Stack Overflow. Live probes returned results from all four localized sites; the API also returned items with other licenses, which ingestion rejects. Production ingestion retains only explicit `CC BY-SA 4.0` items, with original titles, links, author attribution, language and tags; it discards bodies and makes at most 27 queries per daily run. Observed exact tags on repeated questions are surfaced as descriptive sample observations, not trends or leads. [Search API](https://api.stackexchange.com/docs/search-advanced), [API throttles](https://api.stackexchange.com/docs/throttle), [content licensing](https://stackoverflow.com/help/licensing).
- **Live topic exploration:** A visitor can search one selected community using one keyless Stack Exchange API request. Only explicitly CC BY-SA 4.0 items with author attribution are rendered. Queries and results remain in the browser and are not persisted by Signal Scout; Stack Exchange receives the request directly. This improves discovery but does not add an independent source operator or create a qualified thesis lead.
- **Mastodon public hashtag timeline:** The official API allows an unauthenticated public hashtag request when the selected instance has public preview enabled; the instance may deny it, in which case the app does not log in or retry through another route. The current viewer calls only mastodon.social, asks for at most 20 public statuses, filters out non-public/boosted items, displays author/origin server and canonical links, suppresses post bodies when a content warning exists, and keeps returned data in browser memory only. mastodon.social’s effective terms (2026-08-31) state authors retain ownership and license Mastodon GmbH only to operate/maintain the service; therefore Signal Scout does not imply a blanket redistribution license or build a persistent/derived dataset from these posts. This is a narrow interactive public client, not an authorized social-listening archive or complete fediverse view. [Hashtag timeline API](https://docs.joinmastodon.org/methods/timelines/#view-hashtag-timeline), [Terms of Service API](https://docs.joinmastodon.org/methods/instance/).
- **Bluesky:** Public AppView GET endpoints can be called without authentication according to the official API reference, but this deployment previously received HTTP 403. It remains disabled until access is restored under the provider's limits and terms. [Official API reference](https://docs.bsky.app/docs/api/app-bsky-feed-get-feed).

These are implementation notes, not a legal opinion. Recheck source terms before enabling a connector or displaying more than minimal excerpts.

Bluesky is currently disabled after HTTP 403 responses. No Korean forum API/source or direct publisher news feed is currently active. SEC EDGAR is not part of the current homepage evidence flow. Configuration, successful fetches, and permission to display full source text are separate questions; respect publisher/API terms and prefer linking out.
