# Source handling

Production ingestion stores records returned by individually enabled source connectors. Available metadata may include source name/domain, URL, publication time, market/language labels, title, and connector metadata. Metadata completeness depends on the source; source-specific content is filtered according to its reviewed retention and attribution rules.

The scheduled Stack Exchange feed samples the newest public questions from 12 English-, Spanish-, Portuguese-, Japanese-, and Russian-language communities spanning economics, quantitative finance, personal finance, politics, law, AI, data science, security, and programming. It makes at most one request per community per daily run, asks for at most 100 records per community in a rolling 30-day window, and retains only individually CC BY-SA 4.0-licensed titles, tags, dates, canonical links, and author attribution; question and answer bodies are not retained. This is a broad current expert-Q&A feed, not general-purpose public opinion or a representative forum sample; all 12 communities are still one platform operator. API quotas, page limits, source activity, license exclusions, and backoff can reduce coverage. On-demand searches retain citation metadata and discard post bodies. GDELT scheduled ingestion is disabled after repeated HTTP 429 responses; optional visitor searches use a first-party no-store bridge and may still be throttled. Bluesky is available only for transient, citation-only visitor searches; scheduled ingestion and persistence of post text are disabled. No Korean general-forum connector is active.

The currently enabled licensed analysis/reporting feeds include The Conversation's English editions and Global Voices' English, Spanish, French, Portuguese, Arabic, Russian, Italian, Dutch, Yoruba, Ukrainian, Greek, and Catalan editions, alongside separately labeled European Commission official context. These publication feeds are not general forum conversation. Global Voices entries are limited to a seven-day rolling publication window. Individual rights checks and source attribution govern storage; story bodies/summaries are discarded where the connector requires title-only retention. Localized Global Voices editions may carry translations; cross-source review displays feed-provided publisher labels separately from edition names, but neither labels nor multiple editions establish corporate independence.

Lead review's discussion–reporting overlap is computed transiently from eligible Stack Exchange questions, Fedora Discussion topic metadata, and licensed analysis/reporting rows in the preceding seven days. Phrases may be individually CC BY-SA 4.0 Stack Exchange community tags or exact two-to-four-word excerpts from Fedora topic titles. Tags are applied by the source community; Fedora excerpts are generated from titles and are not platform-applied tags. Ambiguous acronym-only phrases and excerpts containing listed English function words are suppressed to reduce generic collisions; this heuristic can omit relevant phrases. Typst Forum topics are not currently included in this overlap view. Matching uses whole token boundaries and does not merge translations or paraphrases. The view returns linked original titles/dates/source labels and caps evidence links per phrase. It is lexical discovery—not proof of shared event, influence, source independence, sentiment, financial materiality, or a lead. No extra content is stored by this calculation.

Wikinews is excluded from live research: the Wikimedia Foundation closed its editions effective 2026-05-04, leaving read-only archives. A live English API search returned only 2024 material, so archive items are not presented as current evidence.

Do not infer source quality, permission to republish, or population representativeness solely from successful retrieval. Preserve attribution and links, minimize copied text, respect source terms and rate limits, and disable a source if the intended use is not permitted.
