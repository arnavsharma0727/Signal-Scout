# Source registry and access review

## GDELT on-demand global news search

Explore can send one visitor-triggered query directly from the browser to the GDELT DOC API. It requests at most 25 results from the last seven days and keeps returned headlines, dates, language, country labels, and publisher URLs only in that visitor's browser; the app does not persist results or queries. The UI links to the publisher and credits GDELT. Its returned source-country field is a publisher/index label, not audience geography or origin of conversation. GDELT's terms permit free academic, commercial, and governmental use, and require citation plus a link to GDELT. The hosted API rate-limits requests to at most one every five seconds; this execution environment repeatedly received HTTP 429 even when requests were spaced, so scheduled server-side ingestion is not considered reliable. The direct-browser search surfaces provider rate limiting and does not retry. GDELT is a news index, not a discussion forum, and matching headlines do not prove independent publishers or constitute a lead.

References: [GDELT DOC API](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/), [GDELT terms of use and attribution](https://www.gdeltproject.org/about.html).

## Mastodon public hashtag viewer

The optional /explore viewer requests one hashtag timeline directly from one of four fixed public Mastodon servers (mastodon.social, mastodon.online, mstdn.jp, mastodon.world), caps each API response at 20, filters to public non-boost statuses, shows author/origin and canonical links, honors content warnings, and does not persist posts or derive metrics. Live probes returned HTTP 200 with browser CORS permission on all four servers. Each is a separate server view, not a country/language proxy; results can overlap due to federation and include RSS syndication, relays, and automation. This is not a complete fediverse or representative population sample. The Mastodon API permits servers to disable public timeline access. mastodon.social's current user terms took effect 2026-08-31 and state that authors retain ownership and license Mastodon GmbH to operate and maintain the service; they do not provide Signal Scout with a blanket license. Keep this a transient public client and re-review rights before introducing scheduled ingestion, retention, or aggregate analysis. Other instances set their own terms. An instance may restrict or rate-limit access; do not authenticate or route around those controls.

References: [Mastodon hashtag timeline API](https://docs.joinmastodon.org/methods/timelines/#view-hashtag-timeline), [rate limits](https://docs.joinmastodon.org/api/rate-limits/), [mastodon.social current Terms of Service endpoint](https://mastodon.social/api/v1/instance/terms_of_service), [Terms of Service API structure](https://docs.joinmastodon.org/entities/TermsOfService/).

## Wikimedia on-demand article-talk search

Explore searches namespace-1 talk pages on a visitor-selected English, Spanish, German, Korean, or Japanese Wikipedia. It requests at most 20 relevance-ranked text-search results; archived pages are excluded and only pages edited within 90 days are displayed. That timestamp is the page's edit time and snippets may quote older discussion. Results and query remain in the visitor's browser; no content is persisted, counted, or fed into leads. Contributor credit is linked through the talk page's history. Wikimedia contributions are generally licensed under CC BY-SA 4.0 and GFDL, subject to project and imported-content exceptions; review the page itself. Talk pages are editorial collaboration, not representative public conversation. API requests identify the app with the required `Api-User-Agent`; respect the current rate policy and `Retry-After`.

References: [MediaWiki search API](https://www.mediawiki.org/wiki/API:Search/en), [Wikimedia API access policy](https://www.mediawiki.org/wiki/Wikimedia_APIs/Access_policy), [Wikimedia API rate limits](https://www.mediawiki.org/wiki/Wikimedia_APIs/Rate_limits), [Wikimedia Foundation Terms of Use](https://foundation.wikimedia.org/wiki/Terms_of_Use?useformat=mobile).
