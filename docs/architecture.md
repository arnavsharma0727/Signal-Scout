# Architecture

Next.js App Router serves the UI and server actions on Vercel. Supabase Postgres stores source metadata, connector runs, private briefs, and researcher-authored leads. A Vercel Cron invokes the protected Next.js `/api/ingest` route once per day; the route uses a server-only Supabase service-role client. Public research searches are visitor-triggered in the browser, except GDELT, which uses a bounded first-party no-store API bridge. Do not assume every on-demand result is stored or included in historical analysis.

The lead queue is human-authored. Current automatic discovery is limited to exact licensed Stack Exchange tag-share prompts and literal same-language discussion-title/reporting-headline overlaps; these are review cues, not a semantic classifier, country comparison, or evidence-qualified lead. Service-role credentials never reach browser code. Anonymous GDELT bridge requests are rate-limited through a service-role-only database function using HMACed request identity and a global cap.
